# Smart Candidate Onboard

Hoje tenho esse cadastro de candidato onde ele precisa preencher tudo manualmente 
Quero trazer o anexo de curriculo pro inicio e com base no curriculo anexado (pdf docx jpg .. ) eu conseguir extrair as informações e preencher nos inputs, focar no principal, informações gerais experiencias e formações, validar a possibilidade de ter um recurso de audio tambem onde ele pode mandar um audio e a ia extrair para os inputs tambem como se fosse um arquivo anexado. 

Coloque essa ideia em pratica preservando o layout das imagens 

Faça uma arquitetura escalável e visando otimização de tokens e custo
